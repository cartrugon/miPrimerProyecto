Objetivo1: Dominar el ciclo completo del desarrollo web: comprender y ser capaz de construir tanto la parte visual de una aplicación (frontend) como la lógica del servidor y la gestión de datos (backend), integrando ambas en un flujo coherente y funcional.

Objetivo2: Construir un portafolio profesional: desarrollar varios proyectos completos durante el máster que sirvan como carta de presentación y demuestren habilidades técnicas y capacidad para resolver problemas reales.

Objetivo3: Prepararse para el entorno laboral o emprendedor: adquirir las metodologías, herramientas y buenas prácticas necesarias para trabajar de forma eficiente en equipos de desarrollo o para lanzar proyectos propios con una base técnica sólida.
